Install on the laptop

  1. Download Qarun-for-Windows.zip and open it. Drag the Qarun folder to Documents (or anywhere).
  2. Open the folder and double-click Qarun.exe. If Windows says "Windows protected your PC", click More info, then Run anyway (the Store version will not ask this).
  3. When Windows asks about the network, allow Private networks, so your phone can reach the laptop over your Wi-Fi.
  4. In Qarun, open Settings & phone → Link a phone. On the phone: ⚙ Settings → Laptop, then type the code (or take a photo of the QR code).
